# Plantilla EICL

Formato común de todas las memorias técnicas: portada, control documental, índice, tablas con encabezado sombreado, recuadros de nota y alerta, estados normalizados (`PENDIENTE`, `EN CURSO`, `COMPLETADA`, `[POR CONFIRMAR]`) y sección final de «Protección de la información».

Paleta: azul marino `#14283F`, azul `#16608B`, turquesa `#16A3A1`, gris `#5D6977`.
